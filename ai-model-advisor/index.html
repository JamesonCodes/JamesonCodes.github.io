Download choose-ai-model-claude.zip for Claude's Customize → Skills upload. Use ai-model-advisor-plugin.zip on supported ChatGPT, Codex, or Claude plugin surfaces. Public directory listings remain subject to platform review.

Optional live OpenRouter research

The plugin can connect through OAuth to OpenRouter's remote MCP server for current model, endpoint, price, benchmark, documentation, and provider lookups. It permits six research-only tools and forbids inference, credits, generation history, and popularity rankings. Users who skip the connection retain web/API/provisional fallbacks.

OpenRouter exposes its complete toolbox after connection. In clients with individual tool controls, disable send-message, get-credits, get-generation, list-daily-model-rankings, and list-app-rankings. AI Model Advisor does not operate a hosted filtering proxy.
