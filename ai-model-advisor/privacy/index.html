Privacy Policy

AI Model Advisor is an instruction-and-code package that runs inside the AI product where you install it. JamesonCodes does not operate a backend for the skill and does not receive your prompts, workflow data, API keys, recommendations, or generated files merely because you install or use it.

OpenRouter MCP

The plugin may connect through your host product to OpenRouter's remote MCP server for model catalog, endpoint, pricing, benchmark, documentation, and provider lookups. Lookup filters and identifiers are transmitted to OpenRouter under its terms and privacy policy. The skill forbids inference, credit, generation-history, and popularity-ranking tools and does not intentionally transmit workflow emails, documents, source code, representative prompts, or evaluation examples through MCP.

The connection uses host-managed OAuth. OpenRouter documents a dedicated credential with a seven-day expiry and configurable spending cap. JamesonCodes does not receive or store it. The server advertises tools beyond the skill's allowlist, so users should disable those tools in clients with individual tool controls.

External sources and providers

Without MCP, the skill may direct your AI product to consult public model catalogs, provider documentation, model cards, and benchmark sources. Those requests are made by the host product and are governed by that product's terms and privacy policy. If you separately choose to run a live model evaluation, the selected access provider processes the evaluation inputs under its own terms and data-handling policy.

Credentials

Do not paste API keys into a conversation. Configure optional credentials using OAuth or the secret and environment-variable controls offered by your runtime. AI Model Advisor does not include telemetry, a hosted backend, or an MCP filtering proxy.

Website hosting

This site is hosted by GitHub Pages. GitHub may process connection and usage information under the GitHub Privacy Statement.
